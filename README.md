## ⭐ Featured Projects

### [Grumpy](https://github.com/joselitojunior94)
**Intelligent multi-miner for software repository analysis.**

Grumpy is an intelligent multi-miner designed to collect, analyze, and structure software repository data. It supports issue analysis, repository mining, dataset construction, and software engineering studies by combining repository metadata, issue information, and analytical workflows.

**Highlights:** GitHub mining, issue analysis, repository analytics, data processing, software engineering research.

---

### [gFetcher](https://github.com/joselitojunior94)
**Python tool for mining GitHub issues and repository metadata.**

gFetcher is a GitHub issue mining tool designed to collect, structure, and export repository data such as issues, labels, comments, reactions, and events. It supports software engineering studies, repository analytics, and dataset construction from open-source projects.

**Highlights:** Python, GitHub API, automation, data mining, issue tracking systems, dataset construction.

---

### [Proap Prod](https://github.com/joselitojunior94)
**University resource and scholarship management system.**

Proap Prod is a university resource and scholarship management system designed to support academic administrative workflows. The system helps manage funding requests, scholarships, resource allocation, approvals, and institutional processes in a structured digital environment.

**Highlights:** full-stack development, administrative systems, workflow management, role-based access, database design.

---

### [ControlHome](https://github.com/joselitojunior94)
**Condominium management system.**

ControlHome is a condominium management system designed to support administrators and residents in daily operational workflows. The system centralizes communication, service requests, user management, and condominium-related processes in a single digital platform.

**Highlights:** web systems, product development, user management, operational workflows, full-stack development.

---

### [Medison Software](https://github.com/joselitojunior94)
**Monitoring system for petroleum pipeline inspection.**

Medison Software is a monitoring system designed to support the analysis and visualization of petroleum pipeline inspection data. The project involves software for industrial monitoring, data visualization, hardware/software integration, and support for ultrasonic wave field analysis.

**Highlights:** industrial software, monitoring systems, data visualization, real-time systems, hardware/software integration.

---

### [Labelor Studio](https://github.com/joselitojunior94)
**Dataset review and annotation tool for Software Engineering studies.**

Labelor Studio is a tool for evaluating, reviewing, and exporting datasets used in Software Engineering studies. It supports dataset inspection, annotation workflows, review processes, and structured data export.

**Highlights:** dataset annotation, software engineering research, data review, web tooling, research infrastructure.
